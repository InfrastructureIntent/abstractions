- Architecture Check passed on the initial PR run.
- The first Test run failed during restore because the package project redundantly referenced `Xml2Doc.MSBuild`; the repository template already injects Xml2Doc through `Directory.Build.targets` for production projects.
- Removed the redundant project-level Xml2Doc reference so the `.csproj` remains project-specific and repository-wide defaults remain centralized.

## Architecture notes

- This repository contains public contracts only.
- Graph algorithms, reference resolution, cycle detection, compiler orchestration, and runtime behavior remain private Engine responsibilities.
- Domain semantic type and managed/existing lifecycle remain orthogonal.
- `ResourceReference<TDomain>` targets an Integration-owned domain contract, not a lifecycle-specific implementation.
- No additional constructor-time validation policy was introduced for identity value types; validation ownership remains with the Integration/Engine layers defined by the ADRs.
