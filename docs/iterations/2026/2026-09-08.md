## Architecture notes

- This repository contains public contracts only.
- Graph algorithms, reference resolution, cycle detection, compiler orchestration, and runtime behavior remain private Engine responsibilities.
- Domain semantic type and managed/existing lifecycle remain orthogonal.
- `ResourceReference<TDomain>` targets an Integration-owned domain contract, not a lifecycle-specific implementation.
- `IntegrationId`, `ResourceType`, and `ResourceKey` are structural contract values and cannot be null, empty, or whitespace.
- Infrastructure-independent structural invariants may be enforced by the public Abstractions value types themselves.
- Integration-specific naming, formatting, scoping, and canonicalization remain Integration responsibilities; enforcing non-empty structural values does not move domain validation into Abstractions.
- ADR-009 is the canonical architecture record for this identity-boundary clarification.
